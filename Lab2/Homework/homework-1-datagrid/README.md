# Homework 1 — Production Enterprise Data-Grid (WCAG 2.2 AA)

A lightweight enterprise-grade Data-Grid application built with TypeScript, modern CSS, and a custom **Mini-React** virtual DOM runtime. It features sortable columns, real-time multi-column search filtering, pagination, keyboard navigation, row selection, and strict protection against XSS vulnerabilities.

---

## 1. Run & Build Instructions

Requires **Node.js 20+** and **npm**.

```sh
# Cài đặt dependencies
npm install

# Khởi chạy dev server cục bộ
npm run dev
